# Flappy Bird OpenGL - Primer Parcial

Este proyecto es una implementación limpia y modular de Flappy Bird utilizando Java, LWJGL y OpenGL 3.3 Core Profile.

## Requerimientos Implementados
- [x] Estructura modular (clases Bird, PipeManager, Shader, Game).
- [x] Modo de dos jugadores simultáneos.
- [x] Controles independientes.

## Controles
- **Jugador 1 (Amarillo)**: Tecla `ESPACIO` para saltar.
- **Jugador 2 (Cian)**: Teclas `W` o `FLECHA ARRIBA` para saltar.
- **Reiniciar**: Tecla `ESPACIO` tras morir ambos.
- **Salir**: Tecla `ESC`.

## Instrucciones de Ejecución
Para compilar y ejecutar el proyecto, asegúrate de tener Maven instalado y ejecuta:

```bash
mvn compile exec:exec
```
